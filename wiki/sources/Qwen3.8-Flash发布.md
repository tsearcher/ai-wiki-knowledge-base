# Qwen3.8-Flash 发布

> 这页是原始资料摘要：新浪科技 2026-08-26 报道，阿里发布并开源千问 Qwen3.8-Flash 模型，千亿参数仅激活 60 亿即超越 Claude Opus4.6，创下模型效率新基准。

## 资料讲什么

`raw/阿里开源Qwen3.8-Flash，性能超Opus4.6价格仅为其3%.md` 报道了 [[Qwen3.8-Flash]] 模型的发布：架构特点、性能表现与成本优势。

## 关键事实

- **发布时间**：2026 年 8 月 26 日晚间，发布并同步开源。
- **定位**：多模态混合专家（MoE）模型，采用下一代（Next）模型架构。

## 架构与性能

- **参数规模**：Transformer 参数 125B（千亿级总参数），推理时仅激活 6B。
- **性能对标**：超越 Claude Opus4.6，接近 Opus4.8。
- **基座模型**：仅完成预训练的 Base 模型，在通用（SuperGPQA）、数学推理（GSM8K）、编程（SWEBench-Pretrain）上超过 3 倍其大小的 Qwen3.7-Plus 基座。
- **后训练跃迁**：SWE-bench Pro（智能体编程）领先 Opus4.6 多达 9.1 分；CoWorkBench（长程专业任务）、Toolathlon Verified（真实工具调用）等智能体任务超越 DeepSeek-V4-Flash。

## 成本优势

| 项目 | 数据 |
| :--- | :--- |
| 训练成本 | 较 Qwen3.7-Plus 骤降近 90%（九分之一资源完成训练） |
| 推理价格（输入） | 每百万 Tokens 1 元 |
| 推理价格（输出） | 每百万 Tokens 3 元 |
| 对比 Claude Opus4.6 | 价格仅为其 3% |
| 对比 DeepSeek-V4-Flash | 闲时价格的 2/3、忙时价格的 1/3 |
