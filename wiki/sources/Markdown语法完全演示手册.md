# Markdown 语法完全演示手册

> 这页是原始资料摘要：一份覆盖 Markdown 核心语法、GFM 扩展、Mermaid 图表、Chart.js 交互图表、LaTeX 数学公式及高亮标记的完整语法参考手册。

## 资料讲什么

`raw/sample.md` 是一份终极版 Markdown 语法演示大全，面向 Typora、Obsidian、GitHub 等主流平台，系统梳理了从基础排版到高级扩展的完整语法体系。

## 内容结构

1. **文档结构与排版**：ATX/Setext 标题、段落换行、分割线。
2. **文字样式与高亮**：加粗、斜体、删除线、==高亮标记==、上下标、Emoji。
3. **列表与任务清单**：无序/有序列表、GFM 任务清单（Todo List）。
4. **链接、图片与自动识别**：行内链接、引用链接、自动链接、图片嵌套与点击跳转。
5. **代码与代码块**：行内代码、围栏代码块（含语法高亮）。
6. **引用块**：嵌套引用、混合标题与列表。
7. **表格**：对齐控制、表格内换行与样式混合。
8. **Mermaid 图表**：流程图、时序图、类图、状态图、饼图、甘特图。
9. **Chart.js 交互式图表**：柱状图、折线图、环形图、雷达图、混合双 Y 轴图、堆叠柱状图、极坐标图。
10. **LaTeX 数学公式**：行内公式、块级公式、极限与积分、矩阵、分段函数、希腊字母。
11. **扩展语法**：定义列表、脚注、缩写。
12. **HTML 混合与转义**：嵌入式 HTML 信息框、`<kbd>` 键盘按键样式、反斜杠转义。

## 关键特性

- Mermaid 代码块语言指定为 `mermaid`，Chart.js 指定为 `chart` 或 `chartjs`。
- LaTeX 行内公式用 `$...$`，块级公式用 `$$...$$`，需编辑器支持 MathJax / KaTeX。
- 高亮标记 `==文本==` 为 Typora / Obsidian 扩展语法，非通用标准。
