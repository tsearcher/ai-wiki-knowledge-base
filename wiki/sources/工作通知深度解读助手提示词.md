# 工作通知深度解读助手提示词

> 这页是原始资料摘要：一份高阶完整版 AI 提示词，用于对公文、工作通知进行深度拆解、风险识别、策略匹配与落地规划，内置复杂问题科学解决方法论工具箱。

## 资料讲什么

`raw/工作通知深度解读助手 _ 高阶完整版提示词（标准Markdown）.md` 是一份可直接使用的 [[Markdown标记语言]] 格式 AI 提示词。它将 AI 定位为「高阶职场落地咨询专家」，目标是让用户"看懂要求、看透规则、避开风险、做对事情、高效落地、超额交付"。

## 固定工作流程（强制四步）

1. **锚定用户身份与解读目的**：根据岗位/身份/职责确立视角、权限、目标；未说明时默认「中层统筹+基层落地双视角」。
2. **通知全文深度结构化解读**：核心主旨、权责主体、显性硬性要求、隐性潜在要求、工作难点卡点、风险与问责分析六维拆解。
3. **方法论匹配落地建议**：先判定复杂度，再匹配工具，输出可落地、可验证、可复盘的策略。
4. **输出可视化工作计划**：标准 Markdown 表格，字段固定为阶段划分、任务、执行标准、时间节点、责任主体、资源协同、风险预判、应对预案、验收标准、复盘机制。

## 内置方法论工具箱

**一、问题诊断层级**
- Cynefin 复杂度框架（简单 / 繁杂 / 复杂 / 混乱 / 失序五域；复杂域执行"探测—感知—响应"）
- 系统思维（系统结构、反馈回路、系统基模，找高杠杆解）

**二、问题拆解与根因重构**
- 第一性原理（抛弃类比与经验主义，从零重构）
- MECE + 逻辑树（相互独立、完全穷尽）
- 5Why + 鱼骨图（人机料法环测多维排查真因）

**三、迭代实验与高速执行**
- 设计思维（同理心→定义→构思→原型→测试）
- 精益创业 / 敏捷（构建—测量—学习闭环，MVP 小步快跑）
- OODA 循环（观察—调整—决策—行动）

**四、矛盾突破与长期战略**
- TRIZ 发明问题解决理论（分离原理、40 个发明原理，解快与稳/多与精类矛盾）
- 情景规划 + 博弈论（多未来情景、博弈均衡、长效策略）

**五、方法论智能匹配规则**

| 工作场景/问题特征 | 优先匹配方法论 |
| :--- | :--- |
| 问题混乱、无从下手、任务庞杂 | Cynefin 框架 + 系统思维 + 逻辑树 |
| 打破旧模式、创新优化、颠覆性改进 | 第一性原理 + TRIZ |
| 问题定义模糊、需求复杂、以人为本 | 设计思维 |
| 方案未知、需要快速试错迭代 | 精益创业、敏捷、OODA 循环 |
| 问题反复复发、治标不治本 | 5Why、鱼骨图、系统基模 |
| 多方协作博弈、长期战略决策 | 博弈论、情景规划 |

## 使用方式

粘贴「工作通知原文 + 岗位身份 + 工作目标（可选）」，即可获得结构化深度解读方案与落地执行计划。输出强制要求贴合职场实际、先诊断复杂度再匹配方法、覆盖显性要求 + 隐性规则 + 风险红线。
