# Markdown 标记语言

> 这页讲一个概念：一种轻量级标记语言，用纯文本格式即可生成结构化的富文本文档，广泛用于技术文档、博客、笔记与版本控制平台。

## 概念说明

Markdown 由 John Gruber 于 2004 年创建，设计目标是让人用易读易写的纯文本格式编写文档，再转换为有效的 HTML。其核心理念是：格式符号本身应当直观可见，不干扰阅读。

## 核心语法

- **标题**：`#` 一至六级 ATX 风格，或 Setext 风格的 `===`/`---`。
- **段落与换行**：空行分隔段落，行尾两空格或 `<br>` 强制换行。
- **文字样式**：`**加粗**`、`*斜体*`、`~~删除线~~`、`` `行内代码` ``。
- **列表**：`-`/`+`/`*` 无序列表，`1.` 有序列表，支持多级缩进。
- **链接与图片**：`[文本](URL)`、`![描述](图片URL)`，支持引用式链接。
- **引用块**：`>` 开头，支持嵌套与内部混合其他元素。
- **代码块**：围栏式 ``` 加语言标识符，实现语法高亮。
- **表格**：`|` 分隔列，`:` 控制对齐方式。
- **分割线**：三个及以上 `-`、`*` 或 `_`。

## 常见扩展（GFM / Typora / Obsidian）

- **任务清单**：`- [x]` 复选框列表。
- **删除线**：`~~文本~~`。
- **高亮标记**：`==文本==`（Typora / Obsidian）。
- **上下标**：`X^2^`、`H~2~O`（部分编辑器）。
- **Emoji**：原生表情或 `:smile:` 简码。
- **Mermaid 图表**：流程图、时序图、类图、状态图、饼图、甘特图。
- **Chart.js 图表**：柱状图、折线图、雷达图等交互式数据可视化。
- **LaTeX 公式**：行内 `$E=mc^2$`、块级 `$$...$$` 数学表达式。
- **脚注与定义列表**：`[^1]` 脚注、`术语\n: 定义` 定义列表。

## HTML 混合

Markdown 允许直接嵌入 HTML 标签，用于实现 Markdown 原生不支持的效果，如自定义样式块、`<kbd>` 键盘按键、`<span>` 颜色文字等。
