# 语义化版本号

> 这页讲一个概念：形如 `vX.Y.Z` 的语义化版本号格式，及其在项目打包命名中的应用。

## 概念说明

语义化版本号用 `vX.Y.Z` 表示：X 为主版本、Y 为次版本、Z 为修订号。在 [[project-packager-Skill]] 的打包命名规范中，归档文件名格式为：

```
{项目名}_{版本号}_{日期}_{类型标识}.{扩展名}
```

例如 `my-app_v1.2.3_20260821_release.zip`、`backend-service_v2.0.0-beta_20260821.tar.gz`。

## 版本号来源优先级

1. 命令行指定（最高优先级）
2. VERSION / version.txt 文件
3. 配置文件：package.json / pyproject.toml / setup.py / Cargo.toml / go.mod
4. Git 标签：`git describe --tags --abbrev=0`
5. 默认值：`unknown`

## 类型标识

release / debug / hotfix / snapshot。
